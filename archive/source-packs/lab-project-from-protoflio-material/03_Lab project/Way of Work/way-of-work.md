# Way of Work

A more human way to build. From curiosity to impact — a structured, iterative process for complex products.

---

**01 — Research**
### Start with curiosity
Explore people, context, and opportunity to find what actually matters.
`Grok 3 / Perplexity`

**02 — Journey Mapping**
### See the bigger picture
Map the end-to-end journey to spot the real opportunity, before designing anything.
`Claude — text reasoning`

**03 — System Setup**
### Create a shared foundation
Turn insights into a design system that aligns people, principles, and components.
`design-system.md`

**03.1 — Static Screens Overview**
### Pressure-test before you build
Lay every screen out side by side and sanity-check the system before moving into interaction.
`Review checkpoint`

**04 — UI Prototype**
### Turn ideas into something real
Design and test high-fidelity, interactive flows with real users, then refine.
`Claude Artifacts`

**05 — Production Code**
### Build real impact
Work with engineers to ship high-quality product — and keep improving after launch.
`Cursor Agent`
