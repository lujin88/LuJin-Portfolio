01 / Foundation

The language already on the site

The HTML islands still label this the Kling AI Design System. The live shell is a near-black surface with a blue-violet signal, not a solid purple fill. Poppins carries the product voice for Display, headings, body, and UI site-wide — no second decorative display face. Film grain, hairline borders, and inverted pills do the rest.

Scope. Global Foundation describes the shared portfolio shell: Index, About, Lab, and AI Workflow. Client Advisory and E.ON Solar inherit that foundation as Theme Layers. They share the React header. Their palettes must not be replaced by the global blue-violet.

Rule of extraction. A value becomes a token only when it repeats across pages. One-off leftovers (unused .tag-chip, unused .btn-primary-kling, unused --color-bg-deepseek) stay out of Global Foundation, Theme Layer, and component tokens.

Global Foundation controls typography, font weights, spacing, layout, containers, radius, borders, shared components, interaction principles, motion, responsive behavior, and the global shell.

Theme Layer may control case-specific palettes, section colors, illustration and media treatments, storytelling motifs, case-specific UI, editorial treatments, and contained light/dark surfaces.

Theme layers inherit the Global Foundation but are not flattened into it.

Near-black atmosphere, not a UI canvas

The page is #0a0a0a with a 3.5% overlay grain. Heroes sit on video with stacked black scrims. Contact and the HTML footer stay transparent so Experience, Contact, and copyright read as one continuous surface.

Type does hierarchy. Color does signaling.

Weight, size, and tracking separate display from body. Blue-violet is reserved for text selection, focus rings, Lab eyebrow, AI Workflow eyebrow / arrows / accents / media wash, card glow, and selected or related shared-shell states. It is not a universal page fill. Body stays cool grey #b6bbc2. Emphasis inside paragraphs is the same family, semibold, in primary white.

One display face, two size tokens

Index and About heroes are Poppins bold, clamp 2.25rem to 4rem, tracking tight. Lab and AI Workflow heroes use the same Poppins face at the larger editorial size token, tracking -0.03em. Timeline eyebrows and Lab index numerals stay Poppins (italic weight where authored).

Image-led, 16:9, 43 / 57

Case-study sections pin a full viewport, then split copy and a rounded media panel at 43fr / 57fr with 48px to 80px gutters. The next case study mirrors the columns. Media is object-cover video inside rounded-2xl with a layered panel shadow.

Invert on interaction, glow only on cards

Primary actions are hollow pills that invert to white fill on hover and lift 2px. Cards keep a 1px hairline and a blue-violet-tinted shadow that strengthens on hover, with a cursor-following glow. No glassmorphism on the shell except the scrolled header blur.

Scroll tells the story. Reduced motion opts out.

Pin-and-scrub case studies, IntersectionObserver reveals (28px rise, 800ms), a 16s ambient hero zoom, and the experience arc are the motion system. At 640px or prefers-reduced-motion, pins collapse to static stacks.

Accent can change. The underlying visual world should remain continuous.

Continuity includes background tone, surface depth, grain / texture, pattern language, spacing rhythm, section transitions, and overall atmosphere. This does not mean every page uses the same background. Client Advisory navy and E.ON light sections are authored Theme Layer surfaces sitting in the same portfolio world, not a hard cut into another site.

Audit

What is inconsistent on purpose, and what is leftover.

  • Two headers. HTML pages still contain #site-nav (1600px, 80px, 15px links, Poppins 700 wordmark). Next.js hides it and mounts SiteHeader (1800px, 80/96px, 17px links, Poppins 600 wordmark, #4a90ff check). The live product is the React header.
  • Layered accents, not one brand blue. Global shell is blue-violet #8B5CF6. Header-local accent is #4a90ff (selected-language Check only). Index Experience connectors are periwinkle #7A7FDC / #3846D4. Do not collapse these; they are different layers.
  • Two footers. Index / About / Lab / AI Workflow use the compact HTML copyright. Client Advisory and E.ON use React SiteFooter with a glow field and larger contact heading. Copy is shared. Chrome is not.
  • One Display family. Index/About/Lab/AI Workflow = Poppins. Size tokens differ; the face does not.
  • Case-study palettes are Theme Layers. Client Advisory ice / signal / navy and E.ON navy / lavender / mint / red / light sections inherit Global Foundation but must never be replaced by global blue-violet. Their tokens are recorded in Color.
  • Leftover CSS, not tokens. --color-bg-deepseek and .btn-primary-kling are unused implementation leftovers. Also unused unless markup proves otherwise: .tag-chip, .social-btn, .app-badge. They are not part of Global Foundation, Theme Layer, or component tokens.
  • Nav current-state contrast. About HTML nav-link default is 88% white with a text-shadow; other pages use 72% and no shadow. Live React header has no underline.
