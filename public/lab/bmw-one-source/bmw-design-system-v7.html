01 · 2020 · Climate control

One control,
three rules.

  1. Hide the control where the market doesn’t allow it.
  2. Show the run time before confirmation.
  3. Show “Running” only after the car replies.

Decision

Hide it,
don’t grey it out.

Option A · Greyed out
ClimateNot available
ControlsRemote access

Drivers read a disabled button as a broken app.

Option B · Hidden · Our choice
ControlsRemote access

Drivers only see what works for their car and market.

The cost: drivers couldn’t see the feature existed elsewhere. We explained it in Help and in the owner’s manual.

02 · 2020 · The cost

Every new model meant an Excel check.

The design held. But which command each car got lived in spreadsheets, outside the system. Every new model added rows, and every yellow cell meant someone checked it by hand.

Over time, more apps shipped and more developers patched components locally. The same Climate control ended up built several ways, so a design could no longer go straight to code.

03 · 2026 · Proposed

Same rules.
One source.

If I rebuilt it today, I’d keep the rules next to the components, not in a spreadsheet. AI tools would do the repetitive building and checking. The team would make the calls.

When a component changes

What I’d test next

Warn before sending when the car’s recent signal is weak, instead of after five minutes on Connecting. A missing reply alone can’t explain why a car is unreachable.

What the team still decides

  • The rulesWhere the control appears and what it does.
  • The timeoutHow long Connecting lasts before it fails.
  • The wordsWhat the error tells a driver in a garage.
  • The variantsWhich patch becomes part of the system.
  • The approvalEvery change the tools flag.

In 2020, the system held the components.
Now it has to hold the rules, and every patch has to come back to it.
