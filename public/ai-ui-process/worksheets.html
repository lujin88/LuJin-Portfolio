方向比较（RICE）Direction comparison (RICE)Richtungsvergleich (RICE)RICE 分数 = 触达 × 影响 × 把握度 ÷ 投入（Intercom 的方法）。尺度：影响 3 很大 / 2 大 / 1 中 / 0.5 小 / 0.25 很小；把握度 100% / 80% / 50%；投入用人周。没有数据的项写“猜测”。RICE = Reach × Impact × Confidence ÷ Effort (Intercom’s method). Scales: impact 3 massive / 2 high / 1 medium / 0.5 low / 0.25 minimal; confidence 100% / 80% / 50%; effort in person-weeks. Mark items without data as “guess”.RICE = Reach × Impact × Confidence ÷ Effort (Methode von Intercom). Skalen: Impact 3 massiv / 2 hoch / 1 mittel / 0.5 niedrig / 0.25 minimal; Confidence 100% / 80% / 50%; Effort in Personenwochen. Markiere Einträge ohne Daten als „Schätzung“.
