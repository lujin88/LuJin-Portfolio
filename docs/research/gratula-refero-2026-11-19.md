## 网页结构（Lu #20555：「蓝色不难看…我现在要找的是网页结构」）
来源：Origin 首页 1440 宽整页图（pm #20495 截的，uploads/a3dc60db.png，720×5399 缩略，cookie 弹窗盖住首屏一块）。Origin 是 Gratula 当年的原参考（pm #20495）。静图；滚动/视差 = 未验。下面是我从图上读到的从上到下顺序，不量像素。
| # | 段 | 结构 |
|---|---|---|
| 1 | Hero | 蓝天底；居中两行标题（后半句斜体衬线）+ 一个按钮；手机居中，下半截压出首屏 |
| 2 | 信任 | 深色；居中一句标题 + 一排奖项徽章 |
| 3 | 三屏横滑 | 三张深色圆角卡并排，每张上手机屏、下标题+一句；下方左右箭头 |
| 4 | 单句 | 居中大标题（斜体衬线）+ 一个小提示条，大留白 |
| 5 | 2 列 × 3 行交错 | 一格全幅照片（标题压在照片上）、一格深色 UI 卡；每行左右互换 |

节奏：居中单句 → 卡片组 → 交错两列 → 通栏图 → 单手机，每段只有一个主体，段与段换版式。Gratula 目前是我们按文字一段段拼的（pm #20529 自己也这么说）。
对 Gratula 可抄：1、3、5 的节奏；照片换成我们的插画场景（Partiful /dinner-invitations：手机压在插画夜景上）。没有的：Origin 全靠照片和深色，Gratula 的 navy 与它的黑不同——Lu 喜欢的是 navy，所以抄结构不抄底色。
